# Web Development - Login & Register Forms

A simple, clean authentication UI built with HTML and CSS. It includes a login page and a registration page styled with a soft neumorphic design.

## Project Structure

```
├── html/
│   ├── login.html       # Login page
│   └── register.html    # Registration page
└── CSS/
    └── resgister.css    # Shared stylesheet for both pages
```

## Pages

### Login
- Email and password input fields
- Login button
- Link to the registration page

### Register
- First name, last name, email, and password input fields
- Register button
- Link back to the login page

## Styling

Both pages share a single stylesheet with a neumorphic design:
- Soft card layout centered on the page
- Light blue (`#a2eaec`) card background
- Inset shadows on inputs for a pressed effect
- Rounded buttons with a hover opacity effect

## Getting Started

Just open either HTML file in your browser — no build tools or dependencies required.

```bash
# Open login page
open html/login.html

# Or open register page
open html/register.html
```
